    \section{Implementation Details}
    \label{app:details}
    
    \paragraph{SFT stage.}
    We fine-tune the base model with LoRA (rank 64, $\alpha{=}128$) on all linear layers.
    The SFT dataset is a mixture of mathematical critique examples and public math reasoning problems (NuminaMath-CoT, MetaMathQA).
    Training runs for 3 epochs with learning rate $5 \times 10^{-5}$, cosine decay (3\% warmup), per-device batch size 2, gradient accumulation 8, and maximum sequence length 8{,}192.
    
    \paragraph{GRPO stage.}
    We optimize the hierarchical TopoPRM reward (Eq.~\ref{eq:r_total}) on the SFT-initialized policy.
    Each prompt samples 4 completions (group size 4) with temperature in $[0.7, 0.9]$, top-$p{=}0.95$, and maximum completion length 2{,}048.
    We use MS-Swift's server-mode architecture~\citep{msswift}: a vLLM rollout server (tensor-parallel) handles generation while a separate training group performs LoRA updates, with NCCL broadcast keeping the rollout adapter current.
    GRPO runs for 200 gradient steps with learning rate $5 \times 10^{-6}$, cosine decay, per-device batch size 2, and gradient accumulation 4.
    
    \paragraph{Reward weights.}
    The base term uses $(w_o, w_f, w_l) = (0.70, 0.15, 0.15)$ and the topology/continuity diagnostics act as multiplicative gain (\S\ref{sec:method}). The default topology--continuity balance is $\alpha{=}0.6$.
    
    \paragraph{Hardware.}
    All experiments use 8$\times$NVIDIA A100-SXM4-80GB GPUs.
    For GRPO, GPUs are partitioned into a 4-GPU rollout server group and a 4-GPU LoRA training group.
    
    \section{SCAE Algorithm}
    \label{app:scae}
    
    \paragraph{Source and adaptation.}
    We follow the formulation introduced in the PASC-GRPO framework~\citet{liu2026graph} and adapt it to our multiplicative hierarchical reward (Eq.~\ref{eq:r_total}). We reuse correct/incorrect stratification and asymmetric advantage clipping, and only replace the identity of the auxiliary reward $r_{\mathrm{aux}}$, which in our setting aggregates the normalized topology/continuity diagnostics $q_{\mathrm{topo}}$ and $q_{\mathrm{cont}}$
    from the implicit DAG rather than PASC-GRPO's symbolic graph signals. Algorithm~\ref{alg:scae} below reproduces the procedure for completeness. The stratified clip bounds the within-stratum contribution of the auxiliary reward $r_{\mathrm{aux}}$ so that structural signals can only re-rank traces inside a correctness stratum, never across it.
    
    \begin{algorithm}[H]
    \caption{Stratified Clipping Advantage Estimation (SCAE)}
    \label{alg:scae}
    \begin{algorithmic}[1]
    \Require Group of completions $\{c^{(1)}, \ldots, c^{(G)}\}$ for prompt $q$
    \Require Outcome rewards $\{R_\mathrm{out}^{(i)}\}_{i=1}^G$, auxiliary rewards $\{r_\mathrm{aux}^{(i)}\}_{i=1}^G$
    \State $\bar{r}_\mathrm{acc} \leftarrow \frac{1}{G}\sum_{i=1}^G R_\mathrm{out}^{(i)}$
    \State $\mathcal{C} \leftarrow \{i : R_\mathrm{out}^{(i)} = 1\}$ \Comment{correct set}
    \State $\mathcal{W} \leftarrow \{j : R_\mathrm{out}^{(j)} = 0\}$ \Comment{incorrect set}
    \State $\bar{r}_\mathrm{aux}^+ \leftarrow \mathrm{mean}(\{r_\mathrm{aux}^{(i)} : i \in \mathcal{C}\})$ if $\mathcal{C} \neq \emptyset$ else $0$
    \State $\bar{r}_\mathrm{aux}^- \leftarrow \mathrm{mean}(\{r_\mathrm{aux}^{(j)} : j \in \mathcal{W}\})$ if $\mathcal{W} \neq \emptyset$ else $0$
    \For{$i \in \mathcal{C}$}
        \State $A^{(i)} \leftarrow (1 - \bar{r}_\mathrm{acc}) + \max(0,\; r_\mathrm{aux}^{(i)} - \bar{r}_\mathrm{aux}^+)$
    \EndFor
    \For{$j \in \mathcal{W}$}
        \State $A^{(j)} \leftarrow -\bar{r}_\mathrm{acc} + \min(0,\; r_\mathrm{aux}^{(j)} - \bar{r}_\mathrm{aux}^-)$
    \EndFor
    \Return Advantages $\{A^{(i)}\}_{i=1}^G$
    \end{algorithmic}
    \end{algorithm}
    
    \section{DAG Extraction Details}
    \label{app:dag}
    
    \paragraph{Extraction pipeline.}
    Given a reasoning trace in \texttt{<think>}, we apply four deterministic stages:
    \begin{enumerate}[leftmargin=*,itemsep=1pt]
        \item \textbf{Step segmentation}. We split the trace by numbered-step markers, mathematical discourse markers (for example ``$\because$'', ``$\therefore$''), and line-level boundaries.
        \item \textbf{Sub-question partitioning}. Markers such as sub-question delimiters (e.g., ``Sub-question~$k$'') define sub-question identifiers. Steps from different identifiers are treated as different connected components in the final graph; cross-sub-question edges are disallowed by construction.
        \item \textbf{Information extraction}. For each step, we extract expressions, claims, and variables with rule-based patterns.
        \item \textbf{Edge construction and verification}. We add dependency edges from explicit evidence and then add weak sequential edges only when strong evidence is absent.
    \end{enumerate}
    
    \paragraph{Information-density constraints.}
    To avoid low-information nodes and noisy links, we use two filters:
    \begin{itemize}[leftmargin=*,itemsep=1pt]
        \item \textbf{Claim completeness}. Claims are extracted at sentence level. Heading fragments and unfinished prefixes (for example, ``all cases are:'') are removed.
        \item \textbf{Expression informativeness}. Trivial tokens (single symbols, pure numerals, and non-relational fragments) are excluded from dependency matching.
    \end{itemize}
    This design biases graph construction toward semantically informative units rather than formatting artifacts.
    
    \paragraph{Dependency rules.}
    For each pair of steps $(r_i, r_j)$ with $i<j$ and the same sub-question identifier, we add a \emph{virtual edge} if at least one of the following holds:
    \begin{enumerate}[leftmargin=*,itemsep=1pt]
        \item \textbf{Expression reuse}: $r_j$ contains an informative expression first introduced in $r_i$.
        \item \textbf{Claim-key reuse}: canonicalized claim keys overlap between $r_i$ and $r_j$.
        \item \textbf{Variable reference}: $r_j$ reuses variables introduced in $r_i$.
    \end{enumerate}
    When a derivation/conclusion step has no explicit support, we insert a \emph{double-barrier edge} from the previous step within the same sub-question as a non-reward fallback connector.
    
    \paragraph{Adaptive sequential weak edges.}
    Consecutive-step weak edges (weight 0.3) are not added unconditionally.
    Under the adaptive mode, a weak sequential edge is added only when the target step does not already have strong incoming support and the source step does not already emit strong outgoing dependencies.
    This rule reduces chain-dominant artifacts and preserves branch structures in long traces.
    
    \paragraph{Node typing and local verdicts.}
    Each node is classified by deterministic keyword rules into
    \textsc{definition}, \textsc{derivation}, \textsc{computation},
    \textsc{conclusion}, \textsc{auxiliary}, \textsc{substitution}, or
    \textsc{case\_analysis}.
    Local verdict labels follow a hybrid strategy: reference labels are copied when available; otherwise fallback rules assign
    \texttt{correct}/\texttt{incorrect}/\texttt{unverifiable} from structural support and contradiction cues.
    
    \section{Reward Function Details}
    \label{app:rewards}
    
    \paragraph{Outcome reward.}
    Parses the model's \texttt{<answer>} JSON to extract the predicted
    student score and critique conclusion. Exact score match yields 1.0;
    within $\pm 1$ yields 0.5. Matching the conclusion adds 0.5 bonus.
    The total is capped and normalized to $[0, 1]$.
    
    \paragraph{Format reward.}
    Checks for \texttt{<think>$\cdots$</think>} and
    \texttt{<answer>$\cdots$</answer>} blocks with valid JSON:
    both present $\to$ 1.0; only valid \texttt{<answer>} $\to$ 0.5; only valid \texttt{<think>} $\to$ 0.1; otherwise $\to$ 0.0.
    
    \paragraph{Length reward.}
    Linear decay from 1.0 (at $\leq$ 2{,}000 characters) to 0.0 (at
    $\geq$ 4{,}000 characters).
    
    \paragraph{Topological structure reward.}
    Defined in \S\ref{sec:reward_module}. The DAG extraction uses rule-based step
    segmentation (numbered steps, mathematical delimiters, logical
    connectives) and dependency detection (shared mathematical expressions,
    variable references).
    
    \paragraph{Continuity reward.}
    Defined in \S\ref{sec:reward_module}. Uses regex-based expression matching
    to verify that each step references expressions or claims from prior
    steps or the problem statement.
    
    \section{Supplementary Mathematical Definitions}
    \label{app:math_details}
    
    \paragraph{Topology score (full form).}
    The topology-quality score used in Eq.~\ref{eq:r_total} is
    \begin{equation}
    \label{eq:r_topo}
    q_{\mathrm{topo}}(\mathcal{G}) =
    \lambda_b\,\mathbb{1}[|\mathcal{V}|>0]
    +\lambda_a\,\mathbb{1}[\mathcal{G}\ \text{acyclic}]
    +\lambda_o\,\mathbb{1}[\rho_{\mathrm{orphan}}(\mathcal{G})=0]
    +\lambda_d\,\delta(\mathcal{G})
    +\lambda_k\,\kappa(\mathcal{G},\mathcal{G}^{*}),
    \end{equation}
    where $\rho_{\mathrm{orphan}}$ is orphan-conclusion ratio, $\delta$ is dependency-direction consistency, and $\kappa$ is reference-edge alignment (optional when reference DAGs exist).
    
    \paragraph{Continuity score (full form).}
    The local continuity quality is
    \begin{equation}
    \label{eq:r_cont}
    q_{\mathrm{cont}}(y)=
    \begin{cases}
    1.0, & \eta(y)=1,\\
    0.8\,\eta(y), & \eta(y)<1,
    \end{cases}
    \qquad
    \eta(y)=\frac{1}{T}\sum_{i=1}^{T}\mathbb{1}[\mathrm{supported}(s_i,s_{<i},q)].
    \end{equation}
    
    \paragraph{Correctness-first stratification.}
    For each group, we partition samples as
    \begin{equation}
    \label{eq:scae_partition}
    \mathcal{C}=\{i\mid r_{\mathrm{out}}^{(i)}\ge\tau\},
    \qquad
    \mathcal{W}=\{i\mid r_{\mathrm{out}}^{(i)}<\tau\}.
    \end{equation}
    Within each stratum, we standardize and asymmetrically clip:
    \begin{equation}
    \label{eq:scae_shape}
    \tilde{r}^{(i)}=
    \begin{cases}
    \mathrm{clip}(z^{(i)},0,1.5), & i\in\mathcal{C},\\
    \mathrm{clip}(z^{(i)},-1.5,0), & i\in\mathcal{W}.
    \end{cases}
    \end{equation}
    
    \paragraph{Topology-conditioned revision dispatch.}
    The revision instruction is generated by
    \begin{equation}
    \label{eq:topo_pr}
    P_r=\psi(r_{\mathrm{out}},q_{\mathrm{topo}},k),
    \end{equation}
    where $k$ denotes an orphan-conclusion position from the extracted DAG.
    The explicit text templates for $\psi$ are implementation-level prompts and are omitted here for brevity.

    \subsection{Origin: Teacher Grading as an Implicit PRM Signal}
    Our work originated from a concrete business that has long-term access to an online teacher-grading platform for Chinese middle-school and high-school mathematics, where professional teachers score student solutions and leave step-level written critiques (``this step is wrong because ...''; ``this conclusion does not follow from step~3''). Each record contains a problem, the student's handwritten reasoning, the teacher's per-step annotations, and a final rubric score.
    
    These data have two properties that matter for reasoning post-training. First, teacher critiques are \emph{step-localized}: they explicitly mark which intermediate step introduces the error, which unsupported claim was overlooked, and which derivation is logically disconnected. Second, the grading rubric is \emph{topology-aware}: teachers routinely penalize solutions that reach a correct final answer through a logically broken chain, and reward solutions that show a clean dependency structure even when the answer is partially wrong. In other words, the grading pipeline natively produces the kind of step-level signals that PRM training usually requires costly human annotation~\citep{lightman2023lets,luo2024omegaprm} or learned verifiers~\citep{wang2024math,thinkprm2025,genprm2026} to approximate.
    
    This observation led to the design choice that defines TopoPRM: instead of asking a learned PRM to judge each step, we extract a deterministic dependency DAG from the trace and let the \emph{topology} of that DAG play the role of a free, verifier-free step-level signal. The teacher-critique dataset thus serves a dual purpose in this paper:
    \begin{itemize}[leftmargin=*,itemsep=2pt]
        \item \textbf{Design source.} It is the grounding behind the failure modes we target (dependency omission, spurious linearization, branch redundancy).
        \item \textbf{In-domain validation set.} Because it includes ground-truth teacher scores and step-level verdicts, it is a high-signal, low-noise testbed for fine-grained ablations on a single architecture--dataset axis.
    \end{itemize}
    We therefore report all main results on public math benchmarks (\S\ref{sec:experiments}) and use the teacher-critique set only for the in-domain ablations below, to avoid conflating in-distribution behavior with benchmark generalization.
    
    \subsection{Dataset and Protocol}
    The validation set contains 7{,}595 items (2{,}181 middle-school, 5{,}414 high-school), each with: problem text, student response, per-step teacher verdict, and an integer rubric score. The model is prompted to output a JSON blob containing (a)~an overall critique conclusion and (b)~a rubric score; the \textbf{Acc} column in Table~\ref{tab:main_private} denotes exact-match on the rubric score, \textbf{Fmt\%} denotes structural JSON compliance, and \textbf{Len} is the mean response length in tokens. All GRPO runs in this section start from the same SFT checkpoint, train for 200 GRPO steps with the default hyperparameters from Appendix~\ref{app:details}, and are evaluated under the unified \texttt{transformers} protocol.

    \paragraph{Observation 1: correctness-first shaping is what unlocks PRM-style gains.}
    Table~\ref{tab:main_private} shows that the full TopoPRM reaches $29.7\%$ overall critique accuracy, with $37.2\%$ on the middle-school subset and $22.3\%$ on the high-school subset. Notably, TopoPRM simultaneously achieves the highest format compliance ($94.6\%$ middle, $89.3\%$ high) \emph{and} the shortest responses (364 / 424 tokens). This pattern is consistent with the hypothesis underlying our reward design: once correctness primacy is enforced (via SCAE, \S\ref{app:scae}), the topology/continuity diagnostics act as a free step-level PRM signal rather than a noisy additive distractor.

    Table~\ref{tab:ablation_cross_scale} extends the same ablation across three backbones. On the 32B backbone, every component contributes positively and the full TopoPRM dominates.     Table~\ref{tab:ablation_length} analyses the accuracy--length trade-off on the same set. Removing topology or continuity monotonically inflates response length \emph{and} reduces accuracy, suggesting that the structural signal is not merely a brevity regularizer but a genuine step-level supervisor. This is the in-domain analog of the public-benchmark token-efficiency pattern reported in Table~\ref{tab:unified_metrics}.

    \paragraph{Observation 4: multiplicative aggregation is essential to avoid reward collapse.}
    Table~\ref{tab:aggregation_ablation} compares reward aggregation strategies. Naive additive linear aggregation leads to severe reward collapse ($75.1\%$ of GRPO batches with zero reward standard deviation); the hierarchical multiplicative formulation (Eq.~\ref{eq:r_total}) reduces this to $37.9\%$. This is an empirical confirmation that, in the teacher-critique regime where correctness is sparse, the reward signal must be structured hierarchically so that topology gains can only \emph{re-rank within a correctness stratum}, not flood the advantage estimation.

    Finally, Table~\ref{tab:structural_metrics} reports DAG-level structural diagnostics on the extracted traces. Models trained with the full TopoPRM reward produce traces with higher acyclicity rates, fewer orphan conclusions, and stronger directional consistency than outcome-only or ablated variants. Since these diagnostics are computed by the same deterministic extractor that drove training, the gains are internal-consistency evidence, not an independent metric; we therefore treat this table as a diagnostic rather than a standalone benchmark result.

    \section{\framework Details}
    \label{appx:tgsd_details}
    
    \framework is an optional compression stage rather than the main contribution of
    TopoPRM. Its goal is to retain the teacher's structural reasoning profile
    while reducing generation length in compact students.
    
    \paragraph{Why pure reverse-KL distillation is insufficient.}
    A naive off-policy distillation~\citep{hinton2015distilling,minillm2023} that minimises
    $\mathcal{L}_{\mathrm{RKL}} = \mathbb{E}_{x\sim\mathcal{D}_f}
    D_{\mathrm{KL}}(\pi_S(\cdot\!\mid\!x)\,\|\,\pi_T(\cdot\!\mid\!x))$
    over filtered teacher traces can fail when teacher rollouts are long and
    often format-incomplete; recent on-policy distillation work attributes the
    same failure to train-test mismatch~\citep{agarwal2024gkd,song2026opdsurvey}.
    In our pilot, only 0.4\% of 32B teacher traces
    closed the required \texttt{<answer>} tag within the training budget, so
    the student did not learn a stable stopping pattern. This failure mode is
    the empirical origin of the reverse-KL row in Table~\ref{tab:compression}
    and motivates the two-phase \framework recipe below.
    
    \paragraph{Pipeline.}
    We train compact students (4B/2B/0.8B) with the two-phase \framework
    procedure summarised in Section~\ref{sec:tgsd}:
    (i) topology-conditioned self-refinement, followed by
    (ii) topology-gated on-policy distillation.
    We keep only format-closed samples and log topology diagnostics
    ($q_{\mathrm{topo}}$, $q_{\mathrm{cont}}$, orphan ratio, acyclicity) for
    all retained traces.
    
    \paragraph{Topology-conditioned self-refinement.}
    Given an initial on-policy attempt $y_{\mathrm{init}}$, we compute
    $(r_{\mathrm{out}},q_{\mathrm{topo}},q_{\mathrm{cont}})$ and construct the
    revision prompt $P_r$ defined in Eq.~\ref{eq:topo_pr}. We then sample
    $y_{\mathrm{rev}}\!\sim\!\pi_\theta(\cdot\mid x,y_{\mathrm{init}},P_r)$ and
    keep $(x,y_{\mathrm{init}},P_r,y_{\mathrm{rev}})$ only when the revised
    response is correct and format-closed. The refined model is trained with
    \begin{equation}
    \label{eq:srt}
    \mathcal{L}_{\mathrm{refine}} =
    -\mathbb{E}\log\pi_\theta(y_{\mathrm{rev}}\mid x,y_{\mathrm{init}},P_r)
    -\mathbb{E}\log\pi_\theta([y_{\mathrm{init}},P_r,y_{\mathrm{rev}}]\mid x).
    \end{equation}
    
    \paragraph{Topology-gated on-policy distillation.}
    For each problem, the student samples an on-policy response
    $y\!\sim\!\pi_\theta(\cdot\mid x)$, while the frozen refined model provides
    token-level targets conditioned on the same topology-aware prompt; this is
    related to OPSDC~\citep{opsdc2026} and ExOPD~\citep{yang2026exopd} but
    substitutes deterministic topology diagnostics for an instruction-conditioned
    or reward-extrapolated teacher. The full objective is given in Eq.~\ref{eq:tgsd}.
    The topology prompt makes the distillation signal focus on structurally
    suspect regions, such as orphan conclusions or continuity breaks, while
    remaining independent of human step labels.
    
    \paragraph{Structural views for distillation (optional).}
    To make the ``critical dependency chain'' intuition of \S\ref{sec:tgsd} concrete, the deterministic extractor exposes three composable views of $\mathcal{G}$ that the distillation pipeline can enable as auxiliary targets:
    \begin{itemize}[leftmargin=*,itemsep=1pt]
        \item \textbf{Step-type contraction.} Consecutive nodes that share a step type (for example successive \textsc{computation} or \textsc{derivation} steps) are merged into a single macro-node; edges are rerouted onto the merged representative.
        \item \textbf{Layer aggregation.} Topological generations of $\mathcal{G}$ are collapsed into a layered chain ``layer $i\!\to\!$layer $i+1$'', which folds parallel branches that do not impose a preferred ordering while respecting all dependency constraints.
        \item \textbf{Transitive sparsification.} The transitive reduction~$\mathrm{tr}(\mathcal{G})$ is used to drop redundant shortcut edges and retain the unique minimal evidence graph that preserves reachability.
    \end{itemize}
    The composition of these views yields a chain whose length is an upper bound on the shortest reachability cover of $\mathcal{G}$, mirroring the critical-path intuition from scheduling while remaining strictly graph-theoretic: on unweighted dependency graphs, we read off the fewest-edge root-to-leaf chain; on weighted variants, the same machinery extends to shortest (or longest, depending on edge semantics) supporting paths.
