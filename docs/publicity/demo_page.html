TopoPRM 最终 Demo 页

Deterministic Verifiable Process Rewards + Reverse-KL Distillation

贡献 A：Verifiable PRM

从 trace 提取 dependency DAG，计算 topology/continuity 两类确定性结构奖励，支持审计与复现实验。

贡献 B：Reverse-KL Distillation

Teacher 轨迹经 process-aware filtering 后蒸馏到 Student，形成 compact chain-like reasoning。

关键边界

  • 可验证奖励是程序化可验证，不是语义证明完备验证
  • dependency DAG 是结构代理，不是真值证明图
  • correctness-first 保证正确性优先
