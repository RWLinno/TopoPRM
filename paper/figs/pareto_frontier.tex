% Accuracy--length Pareto frontier, four benchmarks.

% most sets. Nothing is fitted, smoothed, or invented.
% Machine-readable copy + dominance computation:
%   analysis/pareto_frontier_data.py -> analysis/pareto_frontier_data.csv
%
% x is plotted in kilotokens (cell value / 1000) purely to keep tick labels
% short; y is pass@1 in percent, exactly as tabulated.
%
% FRONTIER. Under acc(A)>=acc(B) and tok(A)<=tok(B) with one strict inequality,
% TopoPRM (Full) is the unique non-dominated row in all four panels, so the
% staircase degenerates to the single-vertex step anchored at that point: the
% dashed L-shape bounds the dominated region, and the other five rows all fall
% inside it. Verified by analysis/pareto_frontier_data.py.

    max space between ticks=28, try min ticks=3,

}
