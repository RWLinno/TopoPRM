TGSD — Topology-Guided Self-Distillation

Three-stage post-training framework for topology-aware reasoning. Method = TopoPRM. Framework = TGSD.

Overview

TGSD post-trains a base reasoner in three stages: an SFT cold-start, a GRPO stage that uses our topology-aware process reward (TopoPRM) with stratified clipping advantage estimation (SCAE), and a topology-guided on-policy distillation (TG-OPD) stage that compresses the resulting policy. DAGs over reasoning traces are extracted in a hybrid (rule + offline LLM) preprocessing step, cached, and consumed by the reward computation as well as the distillation supervision.

Stage 1 — SFT cold start Stage 2 — GRPO + R_topo + SCAE Stage 3 — TG-OPD distillation

Three-stage pipeline

Stage 1

SFT cold-start

  • Fit a base policy on curated reasoning traces (think + answer formatting)
  • Stabilizes generation grammar and shortens warm-up of the GRPO stage
  • Output: π_SFT
▶
Stage 2

GRPO with R_topo + SCAE

  • Hybrid DAG extractor produces cached cached_dag per prompt
  • Composite reward: R_total = R_out · (R_fmt · R_len) · I[G valid] · q_topo
  • Stratified Clipping Advantage Estimation stabilizes group advantages
  • Output: π_GRPO (Teacher)
▶
Stage 3

TG-OPD distillation

  • Student rolls out full sequences; teacher provides token-level supervision
  • Reverse-KL minimization with topology-aware prompt induces DAG-faithful traces
  • Compresses chain-merging and cycle removal into a faster student policy
  • Output: π_TGSD (student / final)

DAG extraction pipeline (offline preprocessing)

Online training and evaluation never invoke the LLM refiner: they only consume the cached schema, falling back to the rule-only extractor when the cache is missing.

Topology-aware reward components

Topology score q_topo

q_topo(G) = λ_b · 1[|V|>0] + λ_a · 1[G acyclic] + λ_o · 1[ρ_orphan = 0] + λ_d · δ(G) + λ_k · κ(G, G*)

δ direction-consistency, κ reference-edge F1, ρ_orphan continuous orphan-support score.

Multi-source aggregation

R_topo = 1[G valid] · q_topo(G) R_total = R_out · (R_fmt · R_len) · R_topo

Correctness primacy is hard: outcome=0 ⇒ R_total=0. R_topo is gated by graph validity and only contributes a topology multiplier, never overrides correctness.

Stratified Clipping Advantage Estimation (SCAE)

SCAE follows prior work and stratifies sampled rollouts into B+ (better than mean) and B− (worse than mean) groups by R_out, then applies asymmetric clipping floors so positive examples cannot collapse below TOPO_SCAE_FLOOR_POS and negative examples cannot collapse above −TOPO_SCAE_FLOOR_NEG. This stabilizes advantage estimation under noisy topology rewards.

Stage III: TG-OPD distillation

The teacher π_GRPO scores per-token distributions on student-rolled-out traces; the student minimizes RKL toward the teacher with a topology-aware prompt template that encourages chain merging and cycle elision over the cached DAG. This produces a smaller, faster student that retains the structural profile of the teacher (audited via direction-consistency, orphan-support, and dep_type histograms).
