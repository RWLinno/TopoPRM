\subsection{Reward Configuration}

The hierarchical reward (Eq.~\ref{eq:r_total}) uses base-term weights $(w_o, w_f, w_l) = (0.70, 0.15, 0.15)$ for outcome, format, and length.
The topology-continuity balance is $\alpha{=}0.6$.
The base floor is 0.05 to prevent zero-variance groups when outcome is uniformly zero.

The gated reward variant (Table~\ref{tab:ablation_compact}, ``w/o ACE'') uses:
$\delta{=}0.1$ (outcome-tier gap, constrained by $\delta < 1/6$),
$\epsilon{=}0.5$ (process-quality influence bound within a tier),
and topo-continuity mix weight 0.5.
Batch-level min-max rescaling of $q_{\mathrm{topo}}$ and $q_{\mathrm{cont}}$ guarantees non-zero reward variance.
    
\subsection{Hardware and Infrastructure}

All experiments use 8$\times$NVIDIA A100-SXM4-80GB GPUs.
For GRPO, GPUs are partitioned into a 4-GPU vLLM rollout server (tensor-parallel) and a 4-GPU LoRA training group, coordinated via MS-Swift's server-mode architecture~\citep{msswift} with NCCL broadcast to keep the rollout adapter current.
The vLLM server uses 60\% GPU memory utilization with a maximum model length of 8192 tokens.

\subsection{Evaluation Protocol}

All public benchmark evaluations use the same protocol: vLLM inference with temperature 0.0 (greedy) for pass@1, and temperature 0.7 with top-$p{=}0.95$ for pass@5/maj@5 sampling.
Maximum generation length is set to 2560 tokens for competition benchmarks (AIME, CNMO, OlympiadBench, Omni-MATH) and 1536 tokens for elementary benchmarks (GSM8K, MATH-500).
MMLU and GPQA-Diamond use a 512-token maximum.
Answer extraction uses regex matching for boxed answers and JSON parsing for structured outputs.

\section{Justification of ACE Algorithm}
\label{app:ace}
We followed the stratified-clipping idea from PASC-GRPO~\citep{liu2026graph} to estimate our multiplicative hierarchical reward (Eq.~\ref{eq:r_total}).
The key modifications are (i) replacing the auxiliary reward $r_{\mathrm{aux}}$ with our normalized topology/continuity diagnostics $q_{\mathrm{topo}}$ and $q_{\mathrm{cont}}$ from the extracted DAG, and (ii) fusing the stratified clip with standard GRPO z-score clipping into the unified form of Eq.~\eqref{eq:ace} \textbf{(the two are equivalent through $z_i^{\pm}\approx(R_i-\bar{r_{acc}})/\sigma_{\pm}$)}. Algorithm~\ref{alg:scae} provides the numerically stable implementation of Stratified Clipping Advantage Estimator (SCAE) from PASC-GRPO. Our modified asymmetric clipping ensures that structural signals can only re-rank traces within a correctness stratum, never across it.
% The stratified clip ensures that structural signals can only re-rank traces within a correctness stratum, never across it.
% Algorithm~\ref{alg:scae} reproduces the procedure.

\begin{algorithm}[H]
\caption{Stratified Clipping Advantage Estimator (SCAE)}
\label{alg:scae}
\begin{algorithmic}[1]
\Require Group of completions $\{c^{(1)}, \ldots, c^{(G)}\}$ for prompt $q$
\Require Outcome rewards $\{R_\mathrm{out}^{(i)}\}_{i=1}^G$, auxiliary rewards $\{r_\mathrm{aux}^{(i)}\}_{i=1}^G$
\State $\bar{r}_\mathrm{acc} \leftarrow \frac{1}{G}\sum_{i=1}^G R_\mathrm{out}^{(i)}$
\State $\mathcal{C} \leftarrow \{i : R_\mathrm{out}^{(i)} = 1\}$ \Comment{correct set}
\State $\mathcal{W} \leftarrow \{j : R_\mathrm{out}^{(j)} = 0\}$ \Comment{incorrect set}
\State $\bar{r}_\mathrm{aux}^+ \leftarrow \mathrm{mean}(\{r_\mathrm{aux}^{(i)} : i \in \mathcal{C}\})$ if $\mathcal{C} \neq \emptyset$ else $0$
\State $\bar{r}_\mathrm{aux}^- \leftarrow \mathrm{mean}(\{r_\mathrm{aux}^{(j)} : j \in \mathcal{W}\})$ if $\mathcal{W} \neq \emptyset$ else $0$
\For{$i \in \mathcal{C}$}
    \State $A^{(i)} \leftarrow (1 - \bar{r}_\mathrm{acc}) + \max(0,\; r_\mathrm{aux}^{(i)} - \bar{r}_\mathrm{aux}^+)$
\EndFor
\For{$j \in \mathcal{W}$}
    \State $A^{(j)} \leftarrow -\bar{r}_\mathrm{acc} + \min(0,\; r_\mathrm{aux}^{(j)} - \bar{r}_\mathrm{aux}^-)$
\EndFor
\Return Advantages $\{A^{(i)}\}_{i=1}^G$
\end{algorithmic}
\end{algorithm}

\section{DAG Extraction Details}
\label{app:dag}

\paragraph{Extraction pipeline.}
Given a reasoning trace in \texttt{<think>}, we apply four training-free stages:
\begin{enumerate}[leftmargin=*,itemsep=1pt]
    \item Step segmentation: split by numbered-step markers, mathematical discourse markers ($\because$, $\therefore$), and line boundaries.
    \item Sub-question partitioning: markers such as ``Sub-question $k$'' define connected components; cross-sub-question edges are disallowed.
    \item Information extraction: for each step, extract expressions, claims, and variables with rule-based patterns.
    \item Edge construction: add dependency edges from explicit evidence (expression reuse, claim-key overlap, variable reference), then add adaptive weak sequential edges only when strong evidence is absent.
\end{enumerate}

\paragraph{Information-density filters.}
To avoid low-information nodes and noisy links: (a) claims are extracted at sentence level, with heading fragments and unfinished prefixes removed; (b) trivial tokens (single symbols, pure numerals, non-relational fragments) are excluded from dependency matching.

\paragraph{Dependency rules.}
For each pair of steps $(r_i, r_j)$ with $i<j$ in the same sub-question, we add an edge if: (1) $r_j$ contains an informative expression first introduced in $r_i$; (2) canonicalized claim keys overlap; or (3) $r_j$ reuses variables introduced in $r_i$.
When a derivation/conclusion step has no explicit support, a fallback edge from the previous step is inserted.

\paragraph{Adaptive sequential weak edges.}
A weak sequential edge (weight 0.3) is added only when the target step lacks strong incoming support and the source step does not already emit strong outgoing dependencies.
This prevents chain-dominant artifacts in long traces.

\paragraph{Node typing.}
Each node is classified into \textsc{definition}, \textsc{derivation}, \textsc{computation}, \textsc{conclusion}, \textsc{auxiliary}, \textsc{substitution}, or \textsc{case\_analysis} by keyword rules.

\paragraph{Relationship between DAG quality and reasoning compression.}
We observe empirically that traces with higher DAG scores (acyclicity, low orphan ratio, strong directional consistency) tend to admit shorter compressed forms under \framework.
Intuitively, a well-structured DAG has fewer redundant branches and shorter critical paths, so the transitive reduction yields a more compact chain.
The topology reward $r_{\mathrm{topo}}$ used during GRPO training (Eq.~\ref{eq:rtopo}) is designed to push the model toward producing such compressible structures, while the DAG score itself serves as a diagnostic metric rather than a direct training signal.

\section{Reward Function Details}
\label{app:rewards}

\paragraph{Outcome reward.}
Parses the model's \texttt{<answer>} JSON to extract the predicted score and critique conclusion.
Exact score match yields 1.0; within $\pm 1$ yields 0.5.
Matching the conclusion adds 0.5 bonus.
The total is capped and normalized to $[0, 1]$.

\paragraph{Format reward.}
Checks for \texttt{<think>$\cdots$</think>} and \texttt{<answer>$\cdots$</answer>} blocks with valid JSON:
both present $\to$ 1.0; only valid \texttt{<answer>} $\to$ 0.5; only valid \texttt{<think>} $\to$ 0.1; otherwise $\to$ 0.0.

\paragraph{Length reward.}
Linear decay from 1.0 (at $\leq$ 2,000 characters) to 0.0 (at $\geq$ 4,000 characters).

\paragraph{Topology reward ($r_{\mathrm{topo}}$).}
The topology reward used as a training signal in GRPO is computed from the DAG quality score $q_{\mathrm{topo}}$ (Eq.~\ref{eq:qtopo_full}).
It aggregates five binary/continuous indicators: valid graph existence, acyclicity, absence of orphan conclusions, dependency-direction consistency, and reference-edge alignment (when reference DAGs are available).

\paragraph{Continuity reward.}
Uses regex-based expression matching to verify that each step references expressions or claims from prior steps or the problem statement.
The continuity score $q_{\mathrm{cont}}$ (Eq.~\ref{eq:qcont_full}) measures the fraction of supported steps.

\section{Supplementary Mathematical Definitions}
\label{app:math_details}

\paragraph{Topology score (full form).}
The topology-quality score used in Eq.~\ref{eq:r_total} is
\begin{equation}
\label{eq:qtopo_full}
q_{\mathrm{topo}}(\mathcal{G}) =\sigma(
\lambda_b\,\mathbb{1}[|\mathcal{V}|>0]
+\lambda_a\,\mathbb{1}[\mathcal{G}\ \text{acyclic}]
+\lambda_o\,\mathbb{1}[\rho_{\mathrm{orphan}}(\mathcal{G})=0]
+\lambda_d\,\delta(\mathcal{G})
+\lambda_k\,\kappa(\mathcal{G},\mathcal{G}^{*})),
\end{equation}
where $\sigma(\cdot)$ denotes the activation and normalized function, $\rho_{\mathrm{orphan}}$ is orphan-conclusion ratio, $\delta$ is dependency-direction consistency, and $\kappa$ is reference-edge alignment (optional when reference DAGs exist). The five indicators in Eq.~\eqref{eq:qtopo_full} are aggregated with weights
$(\lambda_b,\lambda_a,\lambda_o,\lambda_d,\lambda_k){=}(0.1,0.2,0.3,0.2,0.2)$
satisfying $\sum_i \lambda_i {=} 1$, which guarantees $q_{\mathrm{topo}}\!\in\![0,1]$ and is consistent with the $[0,1]$ normalization assumed in Eq.~\eqref{eq:rtopo}. The weights are not uniform because different DAG properties contribute unequally to a faithful simplification of the latent reasoning graph: \emph{orphan-conclusion absence} ($\lambda_o{=}0.3$) is weighted highest because an unsupported terminal node directly invalidates the chain; \emph{acyclicity} and \emph{direction-consistency} ($\lambda_a{=}\lambda_d{=}0.2$) preserve the partial order required for a valid linearisation; \emph{reference-edge alignment} ($\lambda_k{=}0.2$) anchors the trace to ground-truth dependency when available; and \emph{graph existence} ($\lambda_b{=}0.1$) is a cheap sanity check that contributes the least information once the other four pass.

\paragraph{Continuity score (full form).}
The local continuity quality is
\begin{equation}
\label{eq:qcont_full}
q_{\mathrm{cont}}(y)=
\begin{cases}
1.0, & \eta(y)=1,\\
0.8\,\eta(y), & \eta(y)<1,
\end{cases}
\qquad
\eta(y)=\frac{1}{T}\sum_{i=1}^{T}\mathbb{1}[\mathrm{supported}(s_i,s_{<i},q)].
\end{equation}

\noindent\textit{Remark.} Eq.~\eqref{eq:qcont_full} is the engineering-tuned form used in our codebase, equivalent to Eq.~\eqref{eq:qcont} with $\gamma{=}0.8$: when $\eta(y){=}1$ both reduce to $1.0$, and when $\eta(y){<}1$ both reduce to $0.8\eta(y)$.

\paragraph{Correctness-first stratification.}
For each group, we partition samples as
\begin{equation}
\label{eq:scae_partition}
\mathcal{C}=\{i\mid r_{\mathrm{out}}^{(i)}\ge\tau\},
\qquad
\mathcal{W}=\{i\mid r_{\mathrm{out}}^{(i)}<\tau\}.
\end{equation}
Within each stratum, we standardize and asymmetrically clip:
\begin{equation}
\label{eq:scae_shape}
\tilde{r}^{(i)}=
\begin{cases}
\mathrm{clip}(z^{(i)},0,1.5), & i\in\mathcal{C},\\
\mathrm{clip}(z^{(i)},-1.5,0), & i\in\mathcal{W}.
\end{cases}
\end{equation}

\paragraph{Topology-conditioned revision dispatch.}
The revision instruction is generated by
\begin{equation}
\label{eq:topo_pr}
P_r=\psi(r_{\mathrm{out}},q_{\mathrm{topo}},k),
\end{equation}
where $k$ denotes an orphan-conclusion position from the extracted DAG.

\section{Preliminary Experiments on In-Domain Data}
\label{appx:pre_exp}
\label{appx:private_results}

\subsection{Origin: Teacher Grading as an Implicit PRM Signal}
Our work originated from access to an online teacher-grading platform for Chinese middle-school and high-school mathematics, where professional teachers score student solutions and leave step-level written critiques.
Each record contains a problem, the student's reasoning, per-step teacher annotations, and a final rubric score.

These data have two properties relevant to reasoning post-training.
First, teacher critiques are step-localized: they mark which intermediate step introduces an error or which derivation is logically disconnected.
Second, the grading rubric is topology-aware: teachers penalize solutions that reach a correct answer through a broken chain, and reward solutions with clean dependency structure even when the answer is partially wrong.
This observation led to the design of TopoPRM: instead of training a learned PRM to judge each step, we extract a dependency DAG structure and let its topology serve as a free, verifier-free step-level signal.

The teacher-critique dataset serves two purposes: (a) it grounds the failure modes we target (dependency omission, spurious linearization, branch redundancy); (b) it provides a high-signal in-domain validation set for fine-grained ablations.
All main results are reported on public benchmarks (\S\ref{sec:experiments}); the teacher-critique set is used only for the ablations below.

\subsection{Dataset and Protocol}
The validation set contains 7,595 items (2,181 middle-school, 5,414 high-school), each with problem text, student response, per-step teacher verdict, and an integer rubric score.
The model outputs a JSON blob with a critique conclusion and rubric score; Acc denotes exact-match on the rubric score, Fmt\% denotes JSON compliance, and Len is mean response length in tokens.
All GRPO runs start from the same SFT checkpoint, train for 200 steps with the hyperparameters in Table~\ref{tab:hparam}, and are evaluated under the unified protocol.

Table~\ref{tab:ablation_cross_scale} isolates the contribution of every component of the TopoPRM reward on \mbox{Qwen3-32B}, the scale at which the generation cap rarely triggers, and the extracted DAG remains complete enough for the topology diagnostics to be well-calibrated. Three observations follow. \textbf{(i)} Removing the topology signal incurs the largest

\section{\framework Details}
\label{appx:tgsd_details}

\framework is an optional compression stage whose goal is to retain the teacher's structural reasoning profile while reducing generation length in compact students.

\paragraph{Why pure reverse-KL distillation is insufficient.}
A naive off-policy distillation~\citep{hinton2015distilling,minillm2023} that minimises
$\mathcal{L}_{\mathrm{RKL}} = \mathbb{E}_{x\sim\mathcal{D}_f}
D_{\mathrm{KL}}(\pi_S(\cdot\!\mid\!x)\,\|\,\pi_T(\cdot\!\mid\!x))$
over filtered teacher traces can fail when teacher rollouts are long and often format-incomplete.
In our pilot, only 0.4\% of 32B teacher traces closed the required \texttt{<answer>} tag within the training budget, so the student did not learn a stable stopping pattern.
This failure mode is the empirical origin of the reverse-KL row in Table~\ref{tab:compression} and motivates the two-phase \framework recipe below.

\paragraph{Pipeline.}
We train compact students (4B/2B/0.8B) with the two-phase \framework procedure summarised in Section~\ref{sec:tgsd}:
(i) topology-conditioned self-refinement, followed by
(ii) topology-gated on-policy distillation.
We keep only format-closed samples and log topology diagnostics ($q_{\mathrm{topo}}$, $q_{\mathrm{cont}}$, orphan ratio, acyclicity) for all retained traces.

\paragraph{Topology-conditioned self-refinement.}
Given an initial on-policy attempt $y_{\mathrm{init}}$, we compute $(r_{\mathrm{out}},q_{\mathrm{topo}},q_{\mathrm{cont}})$ and construct the revision prompt $P_r$ (Eq.~\ref{eq:topo_pr}).
We then sample $y_{\mathrm{rev}}\!\sim\!\pi_\theta(\cdot\mid x,y_{\mathrm{init}},P_r)$ and keep the tuple only when the revised response is correct and format-closed.
The refined model is trained with
\begin{equation}
\label{eq:srt}
\mathcal{L}_{\mathrm{refine}} =
-\mathbb{E}\log\pi_\theta(y_{\mathrm{rev}}\mid x,y_{\mathrm{init}},P_r)
-\mathbb{E}\log\pi_\theta([y_{\mathrm{init}},P_r,y_{\mathrm{rev}}]\mid x).
\end{equation}

\paragraph{Topology-gated on-policy distillation.}
For each problem, the student samples an on-policy response $y\!\sim\!\pi_\theta(\cdot\mid x)$, while the frozen refined model provides token-level targets conditioned on the same topology-aware prompt.
The full objective is given in Eq.~\ref{eq:tgsd}.
The topology prompt focuses the distillation signal on structurally suspect regions (orphan conclusions, continuity breaks) while remaining independent of human step labels.

\paragraph{Structural views for distillation.}
The extractor exposes three composable views of $\mathcal{G}$:
(a) step-type contraction (merge consecutive same-type nodes);
(b) layer aggregation (fold parallel topological generations into a layered chain);
(c) transitive sparsification (replace $\mathcal{G}$ by its transitive reduction).
The composition yields a chain whose length upper-bounds the shortest reachability cover of $\mathcal{G}$, mirroring the critical-path intuition from project scheduling.
