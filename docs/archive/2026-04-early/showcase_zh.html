❓ 问题与动机

现有 RLVR 训练方法仅依赖最终答案正确性作为奖励信号，存在三个根本性局限：

🔗 推理结构脆弱

模型可能通过逻辑跳跃、循环依赖的推理链获得正确答案，中间步骤缺乏有效监督。

📉 Reward Collapse

多源奖励信号简单加权求和导致训练中奖励方差趋近于零，GRPO 无法区分好坏样本。实测：线性聚合下 93% 的 batch 奖励标准差为零。

📏 推理链冗余

大模型生成的推理链动辄上千 token，其中大量是重复推导或无效探索，浪费推理资源。

层次化奖励聚合公式

Rbase = wo · Routcome + wf · Rformat + wl · Rlength

Rtotal = Rbase × (1 + α · R̃topo + (1−α) · R̃cont)

其中 R̃topo 和 R̃cont 是 batch 级别 min-max 归一化后的过程奖励。过程奖励作为乘性增益而非加性偏移，保证答案正确性始终主导。

🔬 RQ2: 消融实验

拓扑奖励是最重要的过程信号

去掉拓扑奖励后准确率下降 −9.9 个百分点，是所有过程信号中影响最大的。

连续性奖励提供互补价值

去掉连续性奖励后下降 −5.9 个百分点，验证了局部步骤间可追溯性的价值。

Reward Collapse 分析

线性聚合：93.8% 的 batch 奖励标准差为零。
Clipped 聚合：80.0%。
层次化聚合：有效解决崩溃问题。

🎓 RQ4: 蒸馏效果

逆 KL 蒸馏 + 过程感知过滤：学生超越教师

学生超越教师

Qwen3-8B 学生在私有 benchmark 上达到 59.0%，远超 32B 教师的 29.7%。归因于过程感知过滤去除了低质量训练信号。

跨语言泛化

仅用中文批改数据训练的学生在英文 GSM8K 上达到 82.5%，MATH-500 达到 59.8%，与同规模模型竞争力相当。

LRKL = Ex~D[ DKL( πS(·|x) ‖ πT(·|x) ) ]

逆 KL 是 mode-seeking 的：鼓励学生集中于教师的高概率模式，而非平均所有输出。这将图增强的教师推理压缩为紧凑的链式学生推理。
