# TopoPRM 工作总结 (2026-05-30)

## 项目概述

**TopoPRM: Topology-Aware Process Rewards for Verifiable Mathematical Reasoning**

目标：将推理链（CoT）建模为有向无环图（DAG），通过拓扑结构提供密集过程奖励信号，无需人工标注即可实现过程级监督。

投稿：EMNLP 2026 (ARR May cycle)

---

## 实验时间线

### Phase 0: 早期探索 (2026年3月)

**目标：** 建立 baseline，评估主流开源模型在数学推理任务上的表现。

**评估模型：**
- Qwen2.5-7B-Instruct
- Llama-3.1-8B-Instruct
- Qwen3-8B
- Qwen3-32B

**评估数据集：** GSM8K, MATH 等早期 benchmark

**观察：**
- 开源 7-9B 模型在复杂数学推理上仍有较大提升空间
- DeepSeek-R1-Distill-Qwen-7B 作为推理蒸馏模型表现突出，适合作为主力 backbone

**结论：** 选定 DeepSeek-R1-Distill-Qwen-7B 和 Qwen3.5-9B 作为主要实验 backbone。

---

### Phase 1: SFT 冷启动 + GRPO 初步实验 (2026年4月初)

**训练：**
- `sft_deepseek_r1_7b`: 基于 NuminaMath-CoT + MetaMathQA 的 SFT，3651 steps
- GRPO 各变体首次训练：outcome_only, no_topo, no_continuity, hierarchical (Qwen3.5-9B)

**关键配置：**
- LoRA: r=64, alpha=128, dropout=0.05
- Target modules: q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj
- 数据: DAG-annotated SFT/GRPO data

**早期结果 (light200 评估)：**
- Hierarchical 奖励聚合优于单一 outcome-only
- Topology reward 和 continuity reward 各自贡献正向增益

---

### Phase 2: 大规模 GRPO 训练 + mcl4096 (2026年4月-5月)

**训练变体：**
- `grpo_hierarchical_qwen35_9b_mcl4096` (主力)
- `grpo_gated_qwen35_9b_mcl4096` (门控聚合)
- `grpo_no_topo_qwen35_9b_mcl4096` (消融: 无拓扑)
- `grpo_outcome_only_qwen35_9b_mcl4096` (消融: 仅结果)
- `grpo_hierarchical_qwen25_7b` (跨模型迁移)

**观察：**
- mcl4096 (max context length 4096) 显著提升竞赛级问题表现
- Gated 聚合与 hierarchical 表现接近，但训练更稳定
- no_continuity 消融严重退化，证明 continuity reward 是关键组件

## 关键发现与结论

1. **Continuity Reward 是核心组件：** 消融实验表明移除 continuity reward 导致灾难性退化（GSM8K 从 93% 降至 51%），而移除 topology reward 影响较小。

2. **SFT 冷启动至关重要：** 直接在 base 模型上做 GRPO 效果不佳，SFT 提供了必要的格式对齐和基础推理能力。

3. **OPD 蒸馏有效但模型敏感：** Qwen2.5-7B 作为学生模型效果最佳（MATH500 66%），而 DR1-7B 和 Qwen3.5-9B 需要更多调优。

4. **聚合策略：** Hierarchical 和 Gated 聚合表现接近，均优于 outcome-only baseline。

5. **模型规模效应：** 4B 学生模型通过蒸馏可达到 7B base 模型的 ~70% 性能。
